## 📖 About the Project
Traditional EEG devices are often rigid and bulky, limiting their utility for long-term measurements or sensitive subjects like children. This repository contains the data and code supporting our proposed solution: an industrially viable, stretchable, and clutter-free EEG cap powered by flexible dry Ag/AgCl electrodes. 

Designed using an island-bridge structure from stretchable electronics, our conformable device performs similarly to conventional wet-electrode systems in skin-electrode impedance, EEG signal quality, and ERP measurements, but with vastly superior mechanical properties and user convenience.

## 🗂️ Planned Repository Structure
Once the embargo is lifted, the repository will be populated with the following structure:

* `/data` - Raw and pre-processed EEG recordings (e.g., resting state, SSVEP).
* `/src` - Python scripts for signal processing, filtering, and PSD analysis using the Welch method.
* `/hardware` - Design patterns and 3D-printable molds for the stretchable tracks and dry electrodes.
* `/docs` - Detailed usage instructions and hardware replication guidelines.
